# Text Analyser

A beginner Python project that analyses paragraphs.

## Features
- Counts characters and words
- Calculates average word length
- Counts word frequency
- Finds the top 3 meaningful words
- Saves an analysis report
- Provides a Tkinter graphical interface

## Technologies
- Python
- Tkinter
- String manipulation
- File handling

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Run the GUI file:

   python gui.py
